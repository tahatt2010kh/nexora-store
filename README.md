# NEXORA Ready Starter

This package contains a connected Flask backend and a simple English storefront.

## Important before public launch
- Change ADMIN_PASSWORD to a strong private password in your hosting dashboard.
- Keep SECRET_KEY generated by the hosting service.
- This is a starter store, not a complete commercial platform.
- SQLite may lose data on some free hosting redeploys or restarts. Use PostgreSQL/Supabase before relying on it for real orders.
- Payment, SMS, image uploads, legal pages, rate limiting and stronger production security still need to be added.

## Render settings
Build command:
pip install -r requirements.txt

Start command:
gunicorn app:app

Environment variables:
ADMIN_USERNAME = your chosen username
ADMIN_PASSWORD = your private password
SECRET_KEY = generate a secure value
COOKIE_SECURE = 1
